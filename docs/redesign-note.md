# wisdomlens-redesign — what it is

A local stub shell exists at `~/workspace/wisdomlens-redesign/wisdomlens/`
(on the author's machine only — it is **not** a GitHub repo, fork, or branch).

## What it contains

Scaffolding only: 4 skill directories with thin `SKILL.md` files
(~594 lines total), plus `agents/`, `hooks/`, `scripts/`, `tests/`
placeholders. It does **not** contain the full skill content,
hooks, eval harness, or validators.

## Relationship to this repo

**This repo (`CodeWithJuber/wisdomlens`) is the source of truth.**
The redesign stub does not supersede it, is not synced with it,
and should not be treated as a release candidate.

If the redesign becomes a real effort, its work should land here
as normal pull requests — not as a parallel copy.
