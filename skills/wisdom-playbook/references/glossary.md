# Universal Terms Glossary

Key concepts used across both frameworks.

## Core Operating Concepts

| Term | Definition |
|------|-----------|
| **Strategic Patience** | Deliberate endurance under pressure — holding the line without collapse or panic-decisions. Not passive waiting, but active persistence. |
| **Calibrated Trust** | Post-effort release. Full diligence first, then handing off the outcome. Trust after preparation, never instead of it. |
| **Excellence-with-Presence** | Doing work better than the spec while fully attending to it. Presence + exceeded expectations. |
| **The Daily Reset** | A deliberate reconnection practice — reflection, counsel, stillness — that restores capacity during sustained effort. |
| **Structured Consultation** | Gathering genuine input before revealing your own position. Consultation as operating system, not courtesy. |
| **Full Measure** | The discipline of honest measurement — weighing every option on the same scale, with no thumb on the pan. |
| **Deep Conviction** | Purpose you actually believe in and act on — not theoretical agreement but operational commitment. |
| **Heightened Awareness** | Moment-to-moment fidelity to your standards, especially under pressure. |
| **The Inner Saboteur** | The internal pull that makes the wrong action look attractive — rationalization, short-term appeal, complacency. |
| **The Reset Loop** | The recovery cycle: name the error → return to the standard → make the repair → stop repeating it. |
| **Stewardship** | The posture of managing what is entrusted to you, not owning it. Everything is on loan. |
| **The Trust** | Delegated responsibility with accountability attached. The kind of contract only an agent capable of breaking it actually needs. |
| **Inattention** | Running on autopilot with the interpretive loop switched off. Eyes open, noticing nothing. |
| **Deliberate Restraint** | Voluntarily declining things you could reasonably have, to train the muscle that refuses the things that would cost you. |
| **Deep Reflection** | Sustained, focused analysis — presented as the default use of a mind, not a luxury. |

## Decision-Making Terms

| Term | Definition |
|------|-----------|
| **Verification** | Checking inputs independently before acting. Weight every report by source credibility. |
| **Demonstrated Proof** | Evidence from live testing, not theoretical argument. Let reality vote on your model. |
| **The Probe** | A low-cost, reversible test that reveals the counterparty's character before any irreversible commitment. |
| **Full Commitment** | Total buy-in after a collective decision. No foot-dragging after the vote. |
| **The Contingency Clause** | "Assuming no blockers" — contingency built into every commitment. Not hedging; error-handling. |

## Work & Strategy Terms

| Term | Definition |
|------|-----------|
| **The Split** | The recurring pattern of innovation: undifferentiated mass → deliberate separation → new entity sustained by its essential input. |
| **Exact Specification** | Every parameter fixed in advance. Measurable scope, acceptance criteria, stop conditions. |
| **Sustained Effort** | Effort that earns capability as its wage. The deposit that becomes skill. |
| **The Smallest Unit** | The smallest measurable unit of work — nothing too small to matter. The last 2% at full effort. |
| **Planted Capital** | Resources deployed into productive channels — skills, relationships, assets, community. Compounding, not hoarding. |

## People & Communication Terms

| Term | Definition |
|------|-----------|
| **Straight Speech** | Direct, accurate, on-target — no flattery, hedging, or weaponized ambiguity. |
| **Answering One Level Above** | Responding to offense with something better than it. The move that converts adversaries. |
| **Pardon** | Deliberately closing the grievance file as a strength move, not a weakness. It outperforms retaliation because it costs more. |
| **The Standing Middle** | The calibrated position between extremes. Neither excessive nor stingy. |
| **The Lesson** | The specific insight you extract from any event. Events filed without lessons are tuition paid for classes never attended. |

## AI-Age Terms

| Term | Definition |
|------|-----------|
| **The Loop** | Repetition without progress. Motion without state change. |
| **Foam** | Output that rides high, looks loud, but is structurally temporary. Slop. |
| **The Durable-Value Filter** | What remains after contact with reality. The six-month test. |
| **Conjecture** | Plausible guessing that gets you no closer to the truth. The exchange rate is zero. |
| **The Black Box** | A system whose internals are hidden. Audit its seams, not its source code. |
| **Sycophancy** | Agreement with an invoice attached. Flattery optimized for engagement. |
| **Kindling** | The human layer: choosing what to start, where to aim, when to stop. You set it going; the growing was never yours to do. |
